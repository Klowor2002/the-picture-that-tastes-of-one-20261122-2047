A program that draws one picture of a single ingredient: one glossy ripe
strawberry, macro studio shot — rich red flesh, tiny golden seeds, a fresh
green calyx and stem, on a warm cream background with a soft shadow.

## How it works

`main.ts` is a zero-dependency Node program. It rasterizes the strawberry
pixel by pixel in pure TypeScript (body shape, red gradient flesh, seed
grid, gloss highlights, dew droplets, calyx leaves and stem) and encodes
the result as a PNG with a hand-rolled encoder (`node:zlib` + CRC32).
No network, no external assets — every pixel is generated by the code.

## Run it

```sh
node main.ts
```

It writes one image to `/output/entry.png` (1024×1024 PNG, under 1 MiB).
