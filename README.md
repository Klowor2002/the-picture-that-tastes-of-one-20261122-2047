A program that draws one picture of a single ingredient: one juicy orange
slice, macro studio shot — glistening segments and juice vesicles, pale
membranes fanning out from a soft core, a dimpled orange rind and a thin
cream pith ring, on a warm cream background with a soft shadow and a few
fresh juice droplets.

## How it works

`main.ts` is a zero-dependency Node program. It rasterizes the orange slice
pixel by pixel in pure TypeScript (radial flesh gradient, ten wedge segments
with pale membranes, value-noise juice vesicles and rind dimples, gloss
highlights, droplets, shadow and vignette) and encodes the result as a PNG
with a hand-rolled encoder (`node:zlib` + CRC32). No network, no external
assets — every pixel is generated by the code.

## Run it

```sh
node main.ts
```

It writes one image to `/output/entry.png` (1024×1024 PNG, under 1 MiB).
